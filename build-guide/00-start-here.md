# Start Here — Beginner Path (read in order)

You need zero combat-robot experience. Follow the numbers, tick boxes, ask TRC organizers early.

## The 8 steps

1. **Rules + safety (P0):** read SPARC + TRC beetle rules. Removable link, failsafe (spin stops on RC loss), LiPo bag, wheel locks. Message TRC now if running any custom/DIY radio — needs pre-clear.
2. **Buy (BOM.md):** order machining FIRST (longest lead). Electronics while waiting. Filament last.
3. **Machine (manufacturing/pcbway/README.md):** export STEP/DXF → PCBWay quote → verify preview scale → pay. Alt for flat AR500: SendCutSend/OSH Cut.
4. **Materials (manufacturing/materials-guide.md):** steel ring + alu plates + TPU cradle + Ti cleats. Don't order metal until P1 audit says which branch.
5. **Print (3d-printing/README.md):** test-fit in PLA, fight parts in TPU 95A. No pre-sliced files — slice for your printer.
6. **Assemble (01-frame-assembly.md):** dry-fit → balance → Loctite 243 → torque. Balance is the whole game.
7. **Wire + firmware (02-electronics-setup.md + ../firmware/README.md):** bench without weapon → spin-up → translation tune.
8. **Fight prep (03-testing-and-driving.md):** failsafe video, weigh-in ≤1361g, spares (teeth, cleats, ESC, battery).
