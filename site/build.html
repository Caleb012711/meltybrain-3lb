Build in 8 steps

Beginner-first. Do in order. Tick boxes.

0 · Rules + safety

Read SPARC + your event rules. Removable link, failsafe (TX off → stop <1s), LiPo bag, wheel locks. Message organizer now if using ELRS + any DIY radio — needs pre-clear. AI/cloud never drives.

1 · Order metal first

Longest lead. See PCBWay page: export Main CAD.step bodies to cnc/*.step (one solid per file) + flat plates to sheet-metal/*.dxf. AR500 0.25″ ring target 241g, 6061-T6 plates, Ti cleats.

2 · Order electronics

See Parts: 2× PROPDRIVE 2836 1200KV (82g), AM32 55A, Teensy 4.0 LOCK no-pins, 2× H3LIS331DLTR (Adafruit 4627 to start), ELRS EP1 + Pocket, 2× 4S 550mAh parallel.

3 · Print plastics

See printing. Test-fit in PLA, fight in TPU 95A. No pre-sliced G-code — slice for your printer.

4 · Assemble frame

Deburr → hand-thread every bolt → press 626 bearings straight → hubmotor dead-axle + alu hubs + Ti cleats last → ring bolts 12.9 + Loctite 243 star pattern. Balance on point jig: level in 4+ orientations. 3–5g off = hop at 3000 RPM.

5 · Wire (bench, no weapon energy)

Batt → link → AM32s → PropDrives. RX CRSF → Teensy UART. Dual H3LIS on short SPI near CG. 4700µF on 5V, twist power/signal. Heading LEDs (green=front) visible thru poly window. Pi Zero 2W on BEC + TPU standoffs, UART to Teensy, never power Teensy from Pi USB.

6 · Flash + tune

See firmware. Learn on OpenMelt2 (Arduino Micro, 3.9cm radius default), then Teensy DShot600 bidir @8000Hz. Low-RPM slide → trim straight → 2k→3k→4k RPM. One gain at a time, log it.

7 · Failsafe + weigh-in

Film TX-off stop, re-arm needs deliberate action, boot never armed with throttle high. Save as firmware/failsafe-test.mp4. Scale ≤1361g fight-ready. Pack spares: teeth, cleats, ESC, battery.
