What makes this one good

  • Liftoff formula, not guesswork: PropDrive 2836 1200KV hubmotors (6mm dead axle, 2×626), 1.55″ Ti cleats, 0.25″ AR500 ring, TPU shell.
  • Deterministic spin sensing: 2× H3LIS331DLTR opposed @45°, SPI to Teensy 4.0 LOCK, DShot600 bidir @8000Hz. Survives CoR shift after hits.
  • Legal AI: onboard Pi Zero 2W cam (optical flow + log) + pit overhead YOLO + cloud LLM hints. Human-gated, never drives.
  • Weight-safe: P1 mass audit in repo proves steel-ring + alu + TPU path to ≤1361g.
